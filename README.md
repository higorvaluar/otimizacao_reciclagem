# Otimização de Reciclagem Eletrônica

Projeto desenvolvido para a disciplina de Otimização de Sistemas.

## Tecnologias utilizadas

- Java
- Maven
- ojAlgo

## Como executar

1. Abrir o projeto em uma IDE Java, como IntelliJ IDEA.
2. Garantir que o arquivo `dados.csv` esteja na raiz do projeto.
3. Executar a classe `Main.java`.
